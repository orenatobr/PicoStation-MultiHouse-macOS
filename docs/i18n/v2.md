# v2 module: EN-US texts

All user-visible texts of `core/src/v2/*` and `core/include/mh/{v2,v2write,v2format}.h` are EN-US
(sentence case, glossary of docs/UI_DESIGN.md: Case, Disc, Card, Verify, Cheats, Art, Raw write,
Apply Changes). Windows wording was replaced: "erro Win32 N" is now "error N", "Explorador" and
"no Windows" are "Finder", "PhysicalDrive" is "disk", "execute como administrador" is a macOS
permission or eject hint, the path `menu\menu.bin` is "the built-in menu". Line structure
(`\r\n` separators) and placeholder order are unchanged.

## Deliberately untranslated

| Text | Where | Reason |
|---|---|---|
| `PSXRAW`, `PSTCFG2`, `PSTWIP1`, `PSTRSM1`, `PSTTRK1`, `PSTCHT1`, `PSTVFY1`, `CASE`, `DISC` | v2format.h, writer, loader | magic strings and record markers written to, or read from, the card |
| Embedded config text (PSTCFG2 body), menu.bin, music | resources | data on the card |
| `MODE1/2352`, `MODE2/2352`, `EDC/ECC`, `LBA`, `CRC32`, `SHA-1`, `GPT`, `SBI`, `CUE/BIN` | messages | technical terms and file formats |
| `*_BIN_EDC_ECC` folder suffix, `BIN_<n>.bin` file names | v2_recode.c | names of files created on disk, kept for compatibility with copies made by the original |
| `DISC-<id>.sbi`, `CASE-<id>.art`, `menu.bin` cache names | v2_load.c | internal cache file names, not shown |
| Disc and Case titles, game names, serials | data | come from the user or the database |
| `PicoStation Multi House V3` (MH_V2W_MSGBOX_TITLE) | v2write.h | product name |
| `GameShark V5` | hydrate, admit_disc | product name |

## Progress phases

The UI no longer parses progress text. `MhProgress.phase/step/steps` carry the phase
(`MhV2Phase` in v2write.h). Progress texts are for humans only.
